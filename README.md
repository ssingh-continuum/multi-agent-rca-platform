# AI-Powered Incident Resolution Platform
A multi-agent incident intelligence platform built using LangGraph, FastAPI, Ollama, and ChromaDB. The system automates log analysis, semantic retrieval of historical incidents, root cause analysis (RCA), and remediation recommendations through orchestrated AI agents running entirely on local infrastructure.
